TCP/IP คืออะไร?

TCP/IP (Transmission Control Protocol/Internet Protocol) เป็นชุดโปรโตคอลที่ใช้ในอินเทอร์เน็ตและเครือข่ายส่วนใหญ่ทั่วโลก ถูกพัฒนาโดย DARPA ในปี 1970

📘 TCP/IP

  • พัฒนาโดย: DARPA (Defense Advanced Research Projects Agency)
  • ปีที่เริ่ม: 1970s (ARPANET)
  • จำนวน Layers: 4 Layers (Application, Transport, Internet, Physical)
  • สถานะ: มาตรฐานของอินเทอร์เน็ตปัจจุบัน

4 Layers ของ TCP/IP

Layer ชื่อ เทียบกับ OSI Protocol ตัวอย่าง
4 Application Layer 5-7 (Session, Presentation, Application) HTTP, FTP, SMTP, DNS
3 Transport Layer 4 (Transport) TCP, UDP
2 Internet Layer 3 (Network) IP, ICMP, ARP
1 Physical Layer 1-2 (Physical, Data Link) Ethernet, WiFi

ทำไม TCP/IP ถึงเป็นมาตรฐาน?

  • เปิดกว้าง: ไม่ติดลิขสิทธิ์ ใช้ได้ทุกคน
  • ทดสอบแล้ว: ใช้งานมายาวนานบนอินเทอร์เน็ต
  • ยืดหยุ่น: ทำงานบนเครือข่ายหลายประเภท
  • Router ทั่วไป: อุปกรณ์ทุกยี่ห้อรองรับ

เลือก Layer เพื่อดูรายละเอียด

Layer 4: Application

HTTP, FTP, SMTP, DNS

Layer 3: Transport

TCP, UDP, Port Numbers

Layer 2: Internet

IP, ICMP, ARP, Routing

Layer 1: Physical

Ethernet, WiFi
