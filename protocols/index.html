📼 1. โปรโตคอลรุ่นเก่า (Legacy Protocols)

ภาพรวมโปรโตคอลรุ่นเก่า

IPX/SPX, NetBEUI, AppleTalk - เปรียบเทียบและความแตกต่าง

IPX/SPX

Novell NetWare Protocol Suite - ใช้ในเครือข่าย Novell

NetBEUI

NetBIOS Extended User Interface - ของ Microsoft สำหรับ LAN ขนาดเล็ก

AppleTalk

โปรโตคอลของ Apple สำหรับ Macintosh

🌐 2. โปรโตคอล TCP/IP

ภาพรวม TCP/IP

4 Layers: Application, Transport, Internet, Physical

ชั้นแอปพลิเคชัน

HTTP, FTP, SMTP, DNS และ Protocols อื่นๆ

ชั้นทรานสปอร์ต

TCP, UDP, Port Numbers, 3-Way Handshake

ชั้นอินเทอร์เน็ต

IP, ICMP, ARP, Routing Protocols

ชั้นฟิสิคัล

Ethernet, WiFi, Network Interface

เปรียบเทียบ TCP/IP vs OSI

ความเหมือนและความแตกต่างของ 2 แบบจำลอง

📡 3. มาตรฐาน IEEE (802.x)

ภาพรวม IEEE 802

LAN/MAN Standards - มาตรฐานเครือข่ายท้องถิ่น

IEEE 802.3 - Ethernet

Wired LAN Standards - 10Mbps ถึง 400Gbps

IEEE 802.11 - WiFi

Wireless LAN - a, b, g, n, ac, ax (WiFi 6/6E/7)

IEEE 802.15 - WPAN

Bluetooth, Zigbee, Wireless Personal Area Network

IEEE 802.16 - WiMAX

Wireless Metropolitan Area Network

ตารางเปรียบเทียบ

สรุปมาตรฐาน IEEE 802.x ทั้งหมด
