📖 ทฤษฎี: IEEE 802 Standards

IEEE 802 คืออะไร?

IEEE 802 เป็นชุดมาตรฐาน LAN (Local Area Network) และ MAN (Metropolitan Area Network) ที่ IEEE กำหนด ใช้ในเครือข่ายท้องถิ่นและเครือข่ายระดับเมือง

📘 IEEE 802 Committee

  • เริ่มต้น: 1980 (เลข 80 + ปี 2 หลัก = 802)
  • ความรับผิดชอบ: LAN, MAN, PAN Standards
  • Working Groups: หลายกลุ่มย่อย เช่น 802.3, 802.11
  • สัมพันธ์กับ OSI: กำหนด Layer 1 (Physical) และ Layer 2 (Data Link)

ตารางมาตรฐาน IEEE 802

มาตรฐาน ชื่อ รายละเอียด สถานะ
802.1 Bridging & Management การเชื่อมต่อเครือข่าย (VLAN, Spanning Tree) ใช้งาน
802.2 Logical Link Control LLC Sublayer - เชื่อมต่อกับ Network Layer ใช้งาน
802.3 Ethernet Wired LAN - 10Mbps ถึง 400Gbps ใช้งาน
802.4 Token Bus Bus Topology with Token Passing เลิกใช้
802.5 Token Ring Ring Topology (IBM Token Ring) เลิกใช้
802.11 Wireless LAN (WiFi) Wireless Networking - a/b/g/n/ac/ax/be ใช้งาน
802.15 WPAN Bluetooth, Zigbee, UWB ใช้งาน
802.16 WiMAX Wireless Metropolitan Area Network จำกัด
