ภาพรวมบทที่ 3

ประเภท ชื่อเต็ม ระยะทาง ตัวอย่าง สื่อกลาง
LAN Local Area Network < 10 กม. โรงเรียน, สำนักงาน สายเคเบิล, WiFi
MAN Metropolitan Area Network 10–100 กม. เครือข่ายเมือง, ธนาคาร Fiber Optic, Microwave
WAN Wide Area Network > 100 กม. Internet, บริษัทข้ามชาติ Satellite, เคเบิลใต้น้ำ

หัวข้อในบทนี้

🏫 LAN — เครือข่ายท้องถิ่น

Local Area Network

  • เชื่อมอุปกรณ์ในพื้นที่จำกัด
  • ระยะทางไม่เกิน 10 กิโลเมตร
  • ใช้ใน อาคาร / โรงเรียน / สำนักงาน
  • ส่งข้อมูลเร็ว ค่าใช้จ่ายต่ำ
เรียนรู้ LAN →

🏙️ MAN — เครือข่ายระดับเมือง

Metropolitan Area Network

  • เชื่อม LAN หลายวงเข้าด้วยกัน
  • ครอบคลุมระดับเมือง / จังหวัด
  • มี Backbone เป็นกระดูกสันหลัง
  • ใช้ Fiber Optic / Microwave
เรียนรู้ MAN →

🌍 WAN — เครือข่ายระดับประเทศ

Wide Area Network

  • ครอบคลุมระดับประเทศ / ข้ามทวีป
  • ระยะทางตั้งแต่ 100 กม. ขึ้นไป
  • Private Network vs PDN/VAN
  • ใช้ Satellite, เคเบิลใต้น้ำ

🔗 Topology — รูปแบบการเชื่อมต่อ

Network Topology

  • Bus Topology — แบบแถวลำดับ
  • Ring Topology — แบบวงแหวน
  • Star Topology — แบบดาว
  • Mesh Topology — แบบตาข่าย

🖥️ การให้บริการเครือข่าย

Network Services

  • Client-Server — แม่ข่าย/ลูกข่าย
  • Peer-to-Peer — แบบเท่าเทียม
  • เปรียบเทียบข้อดี/ข้อเสีย
  • เลือกแบบไหนให้เหมาะสม

การเชื่อมต่อเครือข่าย 2 แบบ

📌 Point to Point (จุดต่อจุด)

เชื่อมต่อระหว่างอุปกรณ์ 2 ตัว มีช่องทางสื่อสารเฉพาะสำหรับสองอุปกรณ์นั้น ใช้ Microwave หรือ Satellite ได้

📌 Multi Point (หลายจุด)

อุปกรณ์มากกว่า 2 ตัว ใช้ Link ร่วมกัน ประหยัดสาย แต่ข้อมูลอาจชนกันได้หากส่งพร้อมกัน
