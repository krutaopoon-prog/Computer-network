📊 ตารางเปรียบเทียบ OSI 7 Layers

Layer ชื่อ PDU หน้าที่หลัก อุปกรณ์/Protocol
7 Application Data ติดต่อผู้ใช้ ให้บริการเครือข่าย HTTP, FTP, SMTP, DNS, POP3, IMAP
6 Presentation Data แปลงรูปแบบ เข้ารหัส บีบอัด SSL/TLS, JPEG, MPEG, ASCII, EBCDIC
5 Session Data จัดการ Session ควบคุมการติดต่อ NetBIOS, RPC, SQL Session
4 Transport Segment End-to-End Delivery, Flow Control TCP, UDP, Port Numbers
3 Network Packet Logical Addressing, Routing Router, IP, ICMP, ARP
2 Data Link Frame Physical Addressing, Error Detection Switch, MAC, Ethernet, PPP
1 Physical Bits Bit Transmission, Signal Encoding Hub, Cable, Repeater, NIC

แหล่งอ้างอิง: ISO/IEC 7498-1
