การสื่อสารระหว่าง 2 เครื่อง

เมื่อเครื่องคอมพิวเตอร์ A ต้องการส่งข้อมูลไปยังเครื่อง B ข้อมูลจะผ่านกระบวนการสำคัญ 2 อย่าง:

📘 กระบวนการสื่อสาร

  • Encapsulation (การห่อหุ้ม): เพิ่ม Header ทีละชั้นจากบนลงล่าง
  • Decapsulation (การแกะห่อ): ลบ Header ทีละชั้นจากล่างขึ้นบน
  • Peer-to-Peer: ชั้นเดียวกันของเครื่องต่างกันสื่อสารกัน

Encapsulation Process

  1. Application: Data จากผู้ใช้
  2. Presentation: Data + Presentation Header
  3. Session: Data + Session Header
  4. Transport: Segment (ข้อมูลแบ่งเป็นส่วน)
  5. Network: Packet (เพิ่ม IP Address)
  6. Data Link: Frame (เพิ่ม MAC Address)
  7. Physical: Bits (แปลงเป็นสัญญาณ)
📦

Encapsulation

การห่อหุ้มข้อมูล - เพิ่ม Header ทีละชั้นจาก Application ถึง Physical
📂

Decapsulation

การแกะห่อข้อมูล - ลบ Header ทีละชั้นจาก Physical ถึง Application
🤝
