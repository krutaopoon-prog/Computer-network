📖 ทฤษฎี: ISO

ISO คืออะไร?

ISO (International Organization for Standardization) เป็นองค์กรระหว่างประเทศที่กำหนดมาตรฐานอุตสาหกรรมทั่วโลก ก่อตั้งขึ้นในปี 1947 และมีสมาชิกจากประเทศต่างๆ กว่า 160 ประเทศ ทำให้อุปกรณ์และบริการจากทั่วโลกมีคุณภาพและความปลอดภัยที่เชื่อถือได้

📘 ข้อมูลทั่วไป ISO

  • ชื่อเต็ม: International Organization for Standardization
  • ก่อตั้ง: 23 กุมภาพันธ์ 1947
  • สำนักงานใหญ่: เจนีวา ประเทศสวิตเซอร์แลนด์
  • สมาชิก: 167 ประเทศ (National Standards Bodies)
  • มาตรฐานที่ตีพิมพ์: กว่า 23,000 มาตรฐาน
  • ภาษาทำงาน: อังกฤษ, ฝรั่งเศส, รัสเซีย

โครงสร้างองค์กร ISO

ISO ประกอบด้วยสมาชิกจากประเทศต่างๆ ที่เรียกว่า "National Bodies" แต่ละประเทศมีสิทธิ์ออกเสียงหนึ่งเสียง ไม่ว่าประเทศนั้นจะใหญ่หรือเล็ก

  • General Assembly: ที่ประชุมสูงสุดของสมาชิกทั้งหมด
  • Council: คณะกรรมการบริหาร มี 20 สมาชิก
  • Technical Committees (TC): คณะกรรมการเทคนิคที่รับผิดชอบแต่ละสาขา (มีกว่า 250 TCs)
  • Working Groups: กลุ่มย่อยที่พัฒนามาตรฐานเฉพาะทาง

กระบวนการกำหนดมาตรฐาน ISO

  1. Stage 0: Preliminary - เสนอความต้องการมาตรฐานใหม่
  2. Stage 1: Proposal - เสนอโครงการมาตรฐาน (New Work Item Proposal - NWIP)
  3. Stage 2: Preparatory - ร่างมาตรฐานฉบับแรก (Working Draft - WD)
  4. Stage 3: Committee - พิจารณาในคณะกรรมการ (Committee Draft - CD)
  5. Stage 4: Enquiry - สอบถามความคิดเห็นสาธารณะ (Draft International Standard - DIS)
  6. Stage 5: Approval - อนุมัติร่างมาตรฐาน (Final Draft International Standard - FDIS)
  7. Stage 6: Publication - ตีพิมพ์เป็นมาตรฐานสากล (International Standard - IS)

มาตรฐาน ISO ที่เกี่ยวข้องกับเครือข่ายคอมพิวเตอร์

มาตรฐาน ชื่อเต็ม ความสำคัญ
ISO/IEC 7498-1 OSI Basic Reference Model แบบจำลอง 7 Layers สำหรับเครือข่าย
ISO 8802 Local Area Networks (LAN) มาตรฐาน LAN ที่สอดคล้องกับ IEEE 802
ISO/IEC 11801 Generic Cabling for Customer Premises มาตรฐานการเดินสายเคเบิลในอาคาร
ISO 9660 Volume and File Structure of CD-ROM ระบบไฟล์สำหรับ CD-ROM
ISO/IEC 27001 Information Security Management ระบบบริหารความปลอดภัยสารสนเทศ

ความสำคัญของ ISO ต่อเครือข่ายคอมพิวเตอร์

ISO มีบทบาทสำคัญที่สุดในการกำหนด OSI Reference Model (ISO/IEC 7498-1) ซึ่งเป็นแบบจำลองมาตรฐาน 7 ชั้นสำหรับการสื่อสารในเครือข่ายคอมพิวเตอร์

📘 ทำไม OSI Model ถึงสำคัญ?

  • Modularity: แบ่งการทำงานออกเป็นชั้นๆ ทำให้พัฒนาและแก้ไขได้ง่าย
  • Interoperability: อุปกรณ์จากผู้ผลิตต่างกันสื่อสารกันได้
  • Education: เป็นกรอบความคิดสำหรับการเรียนรู้เครือข่าย
  • Troubleshooting: ช่วยแก้ปัญหาได้ง่ายขึ้นโดยแยกตามชั้น

ความสัมพันธ์ระหว่าง ISO กับองค์กรอื่น

  • IEC (International Electrotechnical Commission): ร่วมกันกำหนดมาตรฐานด้านเทคโนโลยีสารสนเทศ (ISO/IEC JTC 1)
  • IEEE: มาตรฐาน IEEE 802 ถูกนำมาเป็น ISO 8802
  • ITU: ความร่วมมือด้านโทรคมนาคม
  • ANSI: ตัวแทนสหรัฐอเมริกาใน ISO
