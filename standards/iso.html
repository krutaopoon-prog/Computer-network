📖 ทฤษฎี: ISO

ISO คืออะไร?

ISO (International Organization for Standardization) เป็นองค์กรระหว่างประเทศที่กำหนดมาตรฐานอุตสาหกรรมทั่วโลก ก่อตั้งขึ้นในปี 1947 และมีสมาชิกจากประเทศต่างๆ กว่า 160 ประเทศ

📘 ข้อมูลทั่วไป

  • ก่อตั้ง: 23 กุมภาพันธ์ 1947
  • สำนักงานใหญ่: เจนีวา ประเทศสวิตเซอร์แลนด์
  • สมาชิก: 167 ประเทศ (National Bodies)
  • มาตรฐานที่ตีพิมพ์: กว่า 23,000 มาตรฐาน

มาตรฐานที่เกี่ยวข้องกับเครือข่าย

  • ISO/IEC 7498-1 - OSI Basic Reference Model (OSI 7 Layers)
  • ISO 8802 - Local Area Networks (LAN)
  • ISO/IEC 11801 - Generic Cabling for Customer Premises
  • ISO 9660 - File system for CD-ROM

ความสำคัญต่อเครือข่าย

ISO มีบทบาทสำคัญในการกำหนด OSI Model ซึ่งเป็นแบบจำลองมาตรฐาน 7 ชั้นสำหรับการสื่อสารในเครือข่ายคอมพิวเตอร์ ทำให้ผู้ผลิตต่างๆ สามารถพัฒนาอุปกรณ์ที่เข้ากันได้
