📖 ทฤษฎี: Physical Layer

หน้าที่ของ Physical Layer

Physical Layer เป็นชั้นล่างสุดของ OSI Model จัดการการสื่อสารกายภาพจริงๆ ผ่านสายเคเบิล สัญญาณไฟฟ้า หรือคลื่นวิทยุ

📘 Physical Layer

  • PDU: Bits (0 และ 1)
  • หน้าที่: ส่งสัญญาณกายภาพ จัดการสื่อส่งข้อมูล
  • อุปกรณ์: Hub, Repeater, Cable, Network Interface
  • Analogy: เหมือนถนนที่รถวิ่ง

หน้าที่หลัก

  • Bit Transmission: ส่ง Bits ผ่านสื่อกายภาพ
  • Physical Topology: กำหนดรูปแบบการเชื่อมต่อ (Bus, Star, Mesh)
  • Signal Encoding: แปลง Bits เป็นสัญญาณไฟฟ้า/แสง/วิทยุ
  • Data Rate: ควบคุมความเร็วการส่งข้อมูล
  • Physical Interface: กำหนดขนาดและรูปแบบ Connector

สื่อส่งข้อมูล (Transmission Media)

  • Twisted Pair Cable: สายคู่บิด (Cat5e, Cat6, Cat6a)
  • Coaxial Cable: สายโคแอกเชียล (รุ่นเก่า, ใช้กับ TV)
  • Fiber Optic: สายใยแก้วนำแสง (Single-mode, Multi-mode)
  • Wireless: คลื่นวิทยุ (Radio, Microwave, Infrared)

อุปกรณ์ใน Physical Layer

  • Hub: ต่อเชื่อมอุปกรณ์หลายเครื่อง (Broadcast ทุก Port)
  • Repeater: ขยายสัญญาณให้ส่งได้ไกลขึ้น
  • NIC (Network Interface Card): การ์ดเครือข่าย
  • Modem: แปลงสัญญาณดิจิตอล↔อนาลอก

Topologies

  • Bus: ต่อบนเส้นทางเดียวกัน (รุ่นเก่า)
  • Star: ต่อรวมศูนย์กลาง (Hub/Switch)
  • Ring: ต่อเป็นวงกลม (Token Ring)
  • Mesh: เชื่อมต่อทุกคู่ (ความปลอดภัยสูง)
