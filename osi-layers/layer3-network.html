📖 ทฤษฎี: Network Layer

หน้าที่ของ Network Layer

Network Layer เป็นชั้นที่กำหนดเส้นทาง (Routing) การส่งข้อมูลจากต้นทางไปยังปลายทาง ผ่าน Network ต่างๆ ใช้ Logical Address (IP Address)

📘 Network Layer

  • PDU: Packet
  • หน้าที่: Logical Addressing, Routing, Path Determination
  • อุปกรณ์: Router, Layer 3 Switch
  • Analogy: เหมือนไปรษณีย์ที่กำหนดเส้นทางจดหมาย

หน้าที่หลัก

  • Logical Addressing: กำหนด IP Address (IPv4/IPv6)
  • Routing: หาเส้นทางที่ดีที่สุดไปยังปลายทาง
  • Packet Forwarding: ส่ง Packet ไปยัง Router ถัดไป
  • Fragmentation: แบ่ง Packet ให้พอดีกับ MTU

Protocol ใน Network Layer

  • IP (Internet Protocol): IPv4, IPv6 - ส่ง Packet หลัก
  • ICMP: Internet Control Message Protocol (Ping, Traceroute)
  • ARP: Address Resolution Protocol - หา MAC จาก IP
  • RARP: Reverse ARP - หา IP จาก MAC
  • Routing Protocols: RIP, OSPF, BGP

IP Address

  • IPv4: 32-bit (เช่น 192.168.1.1) - รองรับ ~4.3 พันล้าน Address
  • IPv6: 128-bit (เช่น 2001:0db8::1) - จำนวนมหาศาล
  • Public IP: ใช้บน Internet
  • Private IP: ใช้ภายในองค์กร (10.x.x.x, 192.168.x.x)
