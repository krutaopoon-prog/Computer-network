📖 ทฤษฎี: Application Layer

หน้าที่ของ Application Layer

Application Layer เป็นชั้นบนสุดของ OSI Model ทำหน้าที่เป็น Interface ระหว่างโปรแกรมที่ผู้ใช้ใช้งานกับเครือข่าย เป็นชั้นที่ผู้ใช้มองเห็นและโต้ตอบโดยตรง

📘 Application Layer

  • PDU: Data
  • หน้าที่: ให้บริการเครือข่ายแก่แอปพลิเคชัน
  • ตัวอย่าง: Web Browser, Email Client, FTP Client
  • Analogy: เหมือนพนักงานต้อนรับที่ช่วยติดต่อราชการแทนเรา

Protocol หลักใน Application Layer

HTTP/HTTPS

HyperText Transfer Protocol - ใช้สำหรับเข้าเว็บไซต์ (Port 80/443)

FTP

File Transfer Protocol - โอนไฟล์ระหว่างเครื่อง (Port 20/21)

SMTP

Simple Mail Transfer Protocol - ส่งอีเมล (Port 25)

POP3/IMAP

รับอีเมล (Port 110/143)

DNS

Domain Name System - แปลงชื่อโดเมนเป็น IP (Port 53)

Telnet/SSH

Remote Access - ควบคุมเครื่องจากระยะไกล (Port 23/22)

หลักการทำงาน

  • รับ Request จากผู้ใช้ (เช่น เปิดเว็บ)
  • สร้างข้อมูลที่จะส่ง (Data)
  • ส่งต่อให้ Presentation Layer
  • รับ Response กลับมาแสดงผู้ใช้
