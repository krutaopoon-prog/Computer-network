📖 ทฤษฎี: Transport Layer

หน้าที่ของ Transport Layer

Transport Layer เป็นชั้นที่สำคัญที่สุดสำหรับการสื่อสาร End-to-End ระหว่างแอปพลิเคชัน ควบคุมการส่งข้อมูลให้ถูกต้องและครบถ้วน

📘 Transport Layer

  • PDU: Segment (TCP) / Datagram (UDP)
  • หน้าที่: End-to-End Delivery, Flow Control, Error Control
  • Protocol: TCP (reliable), UDP (fast)
  • Analogy: เหมือนบริษัทขนส่งที่รับประกันของถึงมือ

TCP vs UDP

คุณสมบัติ TCP UDP
ความน่าเชื่อถือ สูง (Reliable) ต่ำ (Best Effort)
การติดต่อ Connection-Oriented Connectionless
ความเร็ว ช้ากว่า เร็วกว่า
ใช้กับ Web, Email, File Transfer Streaming, Gaming, DNS

Port Numbers

  • Well-known Ports: 0-1023 (HTTP:80, HTTPS:443, FTP:21)
  • Registered Ports: 1024-49151
  • Dynamic/Private: 49152-65535
