📖 สรุปหน้าที่แต่ละ Layer

ตารางสรุป OSI 7 Layers

Layer ชื่อ PDU หน้าที่หลัก อุปกรณ์/Protocol
7 Application Data ติดต่อกับผู้ใช้ ให้บริการเครือข่าย HTTP FTP SMTP DNS
6 Presentation Data แปลงรูปแบบข้อมูล เข้ารหัส บีบอัด SSL/TLS JPEG ASCII
5 Session Data จัดการ Session ควบคุมการติดต่อ NetBIOS RPC
4 Transport Segment End-to-End ควบคุมการส่งข้อมูล TCP UDP Port
3 Network Packet กำหนดเส้นทาง ค้นหา IP Router IP ICMP
2 Data Link Frame จัดการ MAC Address, Error Check Switch MAC Ethernet
1 Physical Bits สื่อสารกายภาพ ส่งสัญญาณ Hub Cable Repeater

หลักการสำคัญ

  • PDU (Protocol Data Unit): หน่วยข้อมูลที่แต่ละชั้นใช้
  • Encapsulation: เพิ่ม Header ตอนส่งข้อมูล (จากบนลงล่าง)
  • Decapsulation: ลบ Header ตอนรับข้อมูล (จากล่างขึ้นบน)
  • Peer-to-Peer: ชั้นเดียวกันสื่อสารกันโดยตรง

เลือก Layer เพื่อดูรายละเอียด
