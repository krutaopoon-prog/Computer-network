📖 ทฤษฎี: Session Layer

หน้าที่ของ Session Layer

Session Layer จัดการ "การสนทนา" ระหว่างแอปพลิเคชันสองฝ่าย กำหนดว่าจะเริ่มต้น ดำเนินการ และสิ้นสุดการติดต่อเมื่อไหร่

📘 Session Layer

  • PDU: Data
  • หน้าที่: Session Management, Dialog Control
  • หน้าที่หลัก: จัดการ Session (เริ่ม รักษา สิ้นสุด)
  • Analogy: เหมือนโฮสต์รายการที่ควบคุมการสนทนา

หน้าที่หลัก 3 ประการ

  • Session Establishment: สร้างการเชื่อมต่อระหว่างแอปพลิเคชัน
  • Session Maintenance: รักษาการเชื่อมต่อและซิงโครไนซ์
  • Session Termination: ยุติการเชื่อมต่ออย่างถูกต้อง

Dialog Control (การควบคุมบทสนทนา)

  • Simplex: ส่งทางเดียว (วิทยุ AM/FM)
  • Half-Duplex: ส่งสลับกัน (วอลกี้-talkie)
  • Full-Duplex: ส่งพร้อมกันทั้งสองฝ่าย (โทรศัพท์)

ตัวอย่าง Protocol

  • NetBIOS: Network Basic Input/Output System
  • RPC: Remote Procedure Call
  • SQL: Session สำหรับฐานข้อมูล
