📖 ทฤษฎี: Data Link Layer

หน้าที่ของ Data Link Layer

Data Link Layer จัดการการส่งข้อมูลระหว่างอุปกรณ์ในเครือข่ายเดียวกัน (LAN) ใช้ Physical Address (MAC Address) และตรวจสอบความผิดพลาด

📘 Data Link Layer

  • PDU: Frame
  • หน้าที่: Physical Addressing, MAC, Error Detection
  • อุปกรณ์: Switch, Bridge, Network Interface Card (NIC)
  • Analogy: เหมือนพนักงานส่งของในหมู่บ้านเดียวกัน

2 ส่วนย่อยของ Data Link Layer

  • LLC (Logical Link Control): จัดการการเชื่อมต่อกับ Network Layer
  • MAC (Media Access Control): ควบคุมการเข้าถึงสื่อ, กำหนด MAC Address

MAC Address

  • ความยาว: 48-bit (6 bytes)
  • รูปแบบ: 12 ตัวอักษร Hex (เช่น 00:1A:2B:3C:4D:5E)
  • Unique: ไม่ซ้ำกันทั่วโลก (กำหนดโดยผู้ผลิต)
  • ที่อยู่: ฝังอยู่ใน Network Card (Hardware Address)

Protocol ใน Data Link Layer

  • Ethernet: มาตรฐาน LAN ที่ใช้ทั่วไป (IEEE 802.3)
  • PPP: Point-to-Point Protocol (Dial-up)
  • Frame Relay: WAN Technology (รุ่นเก่า)
  • ATM: Asynchronous Transfer Mode
  • HDLC: High-Level Data Link Control

Error Detection

  • CRC (Cyclic Redundancy Check): ตรวจสอบความถูกต้องของ Frame
  • FCS (Frame Check Sequence): ส่วนท้ายของ Frame สำหรับตรวจสอบ
