# 🌐 เครือข่ายคอมพิวเตอร์ - Interactive Simulators

> โปรเจกต์ Simulator สำหรับเรียนรู้เครือข่ายคอมพิวเตอร์แบบโต้ตอบ สำหรับนักศึกษาอาชีวศึกษา (ปวช./ปวส.)

## 📚 เนื้อหา

### บทที่ 1: มาตรฐานเครือข่ายคอมพิวเตอร์
- **1.1 ISO** - International Organization for Standardization
- **1.2 ITU** - International Telecommunication Union
- **1.3 ANSI** - American National Standards Institute
- **1.4 IEEE** - Institute of Electrical and Electronics Engineers
- **1.5 EIA** - Electronic Industries Alliance

### บทที่ 2: แบบจำลอง OSI
- **OSI 7 Layers Model** - ภาพรวมแบบจำลอง 7 ชั้น
- **Interactive OSI Diagram** - ไดอะแกรมโต้ตอบ

### บทที่ 3: หน้าที่แต่ละ Layer
- **Layer 7** - Application Layer (HTTP, FTP, SMTP, DNS)
- **Layer 6** - Presentation Layer (Encryption, Compression)
- **Layer 5** - Session Layer (Session Management)
- **Layer 4** - Transport Layer (TCP, UDP)
- **Layer 3** - Network Layer (IP, Routing)
- **Layer 2** - Data Link Layer (MAC, Ethernet)
- **Layer 1** - Physical Layer (Cable, Signal)

### บทที่ 4: การสื่อสารบน OSI
- **Encapsulation** - การห่อหุ้มข้อมูล
- **Decapsulation** - การแกะห่อข้อมูล
- **Peer-to-Peer** - การสื่อสารระหว่างชั้น
- **Data Journey** - การเดินทางของข้อมูล

### บทที่ 5: โปรโตคอลและมาตรฐาน IEEE
- **โปรโตคอลรุ่นเก่า** - IPX/SPX, NetBEUI, AppleTalk
- **TCP/IP** - 4 Layers (Application, Transport, Internet, Physical)
- **IEEE 802** - Ethernet, WiFi, Bluetooth, WiMAX

## 🚀 การใช้งาน

1. เปิดไฟล์ `index.html` ในเบราวเซอร์
2. เลือกหัวข้อที่ต้องการเรียนรู้
3. อ่านทฤษฎี (Theory Section) ก่อน
4. ใช้ Interactive Simulator
5. ทำแบบทดสอบ (Quiz)

## 🎨 Features

- ✅ **Theory Section** - อธิบายทฤษฎีพร้อมแหล่งอ้างอิง

- ✅ **Quiz System** - แบบทดสอบพร้อมผลลัพธ์
